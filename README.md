# 海鸥不下班 · Seagull Bay

Play: https://lyreyja.com/seagull-demo/

A stylized low-poly desktop browser game. Choose free flight or a 90-second challenge. Fly, eat fries, and cause seaside mischief.

Controls: W/S speed, A/D turn, Space/C climb/descend, Shift boost, mouse to look, left click to drop, Esc to pause.

This repository contains the compiled website only. Source code is maintained separately. No account or install required; WebGL 2 and a keyboard/mouse are needed.

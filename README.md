# 海鸥不下班 · Seagull Bay

Play: https://lyreyja.com/seagull-demo/

A stylized low-poly desktop and mobile browser game. Choose free flight or a 90-second challenge. Fly, eat fries, and cause seaside mischief.

Controls: W/S speed, A/D turn, Shift boost, mouse to steer and pitch, left click to drop, hold right click to slow down, Esc to pause. Camera sensitivity is adjustable in the pause menu.

This repository contains the compiled website only. Source code is maintained separately. No account or install required; WebGL 2 is needed. Desktop supports keyboard/mouse; phones support a left thumb stick plus right-side swipe to steer/pitch and boost/fire buttons.

Includes an original procedural seaside BGM loop and distinct effects. Sound starts after selecting a mode, pauses with the game, and can be muted or adjusted in the pause menu.

The bay includes tourists who snack, restock and guard their fries, four foraging crabs and two beach dogs. Skim past a tourist to snatch fries, explore tide pools and picnic areas, and build escalating combos.
